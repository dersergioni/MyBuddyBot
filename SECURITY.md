# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in MyBuddyBot, please report it responsibly.

**Do not open a public issue for security vulnerabilities.**

### How to Report

1. **Email:** Send details to [contact@dersergioni.com](mailto:contact@dersergioni.com)
2. **Subject:** Use the prefix `[SECURITY]` in your email subject

### What to Include

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fixes (optional)

### Response Timeline

- **Acknowledgment:** Within 48 hours
- **Initial Assessment:** Within 7 days
- **Resolution:** Depends on severity, typically within 30 days

### After Reporting

- We will investigate and validate the report
- We will work on a fix and coordinate disclosure
- Credit will be given to reporters (unless anonymity is preferred)

## Security Best Practices

When running MyBuddyBot:

1. **Never commit API tokens** to version control
2. **Use environment variables** for all sensitive configuration
3. **Keep dependencies updated** to receive security patches
4. **Run with minimal privileges** required for operation
5. **Review logs** for suspicious activity
